# Tabela Periódica Interativa 
# Descrição (Ainda em desenvolvimento)
Este projeto é uma tabela periódica interativa desenvolvida em HTML e CSS. Cada elemento da tabela pode exibir informações adicionais ao ser clicado ou ao passar o mouse sobre ele, proporcionando uma maneira divertida e educativa de aprender sobre os elementos químicos.

# Funcionalidades
Visualização da Tabela Periódica: Exibe todos os elementos organizados em suas respectivas posições na tabela periódica.

Informações dos Elementos: Cada elemento apresenta informações detalhadas, incluindo símbolo, nome, número atômico e massa atômica.

Interatividade: O usuário pode interagir com os elementos para obter mais detalhes, tornando o aprendizado mais envolvente.

# Tecnologias Utilizadas
HTML: Estrutura básica da tabela periódica.

CSS: Estilização para tornar a tabela visualmente atraente e responsiva.

JavaScript (opcional): Para adicionar funcionalidades interativas adicionais, como animações ao passar o mouse sobre os elementos.
